Domain 1: Application Design and Build (Questions 1–5)

Question 1

A Dockerfile has ENTRYPOINT ["python3", "app.py"] and CMD ["--port", "8080"]. In a Kubernetes Pod manifest, you define:

yaml
args: ["--port", "9090"]

What command is executed when the container starts?

Answer: C — In Kubernetes, args overrides CMD in the Dockerfile while preserving ENTRYPOINT. (command overrides ENTRYPOINT.)
Question 2

You need a container to fetch configuration from an external API and write it to a shared volume before the main application container starts, and then exit. Which pattern should you use?

Answer: C — Init containers run sequentially to completion before main containers start.
Question 3

Which statement is true about a Job configured with completions: 4, parallelism: 2, and backoffLimit: 3?

Answer: B — completions = total successful Pods required (4), parallelism = max concurrent Pods (2), backoffLimit = max failed Pod retries (3).
Question 4

A Deployment with replicas: 3 uses a single PersistentVolumeClaim with access mode ReadWriteOnce (RWO) across a 3-node cluster. What happens?

Answer: B — ReadWriteOnce binds the volume to a single Node. Multiple Pods on that same Node can mount it, but Pods on other Nodes cannot.
Question 5

What is a key difference between ReadWriteOnce (RWO) and ReadWriteOncePod (RWOP)?

Answer: A — RWO restricts read-write mounting to one Node; RWOP (Kubernetes 1.29+ GA) restricts read-write mounting to a single Pod.

Domain 2: Application Deployment (Questions 6–10)

Question 6

During a RollingUpdate on a Deployment with replicas: 4, maxSurge: 25%, and maxUnavailable: 25%, what is the maximum number of Pods that can exist at once during the update?

Answer: B — 4 desired + 25% of 4 (1 surge) = 5 Pods max during the rolling update.
Question 7

You want to perform a Blue-Green deployment using standard Kubernetes objects so traffic switches instantaneously from v1 to v2. How do you switch traffic?

Answer: B — Blue-Green runs both versions simultaneously behind separate labels; switching the Service's selector instantly routes traffic to the new version.
Question 8

Which statement about HorizontalPodAutoscaler (HPA) is false?

Answer: D — HPA scales the number of replicas, not container CPU/memory limits (that would be VPA — Vertical Pod Autoscaler).
Question 9

You want to deploy a Helm chart named bitnami/nginx as release web in namespace frontend (creating the namespace if it doesn't exist) while overriding replicaCount to 3. Which command works?

Answer: A — helm install <release> <chart> -n <ns> --create-namespace --set key=val is the standard Helm v3 syntax.
Question 10

A Pod has a nodeAffinity rule of type preferredDuringSchedulingIgnoredDuringExecution, and no nodes in the cluster match the label expression. What happens to the Pod?

Answer: B — preferredDuringSchedulingIgnoredDuringExecution is a soft preference; if no Node matches, the scheduler places the Pod elsewhere.

Domain 3: Application Observability and Maintenance (Questions 11–14)

Question 11

A legacy application takes 60 seconds to initialize before its HTTP endpoint responds, after which it responds every second. Which probe configuration best prevents Kubernetes from killing the container during startup while still catching deadlocks quickly once running?

Answer: C — startupProbe disables liveness/readiness probes during the slow boot window without compromising fast deadlock detection afterward.
Question 12

A container's readinessProbe starts failing, while its livenessProbe continues to succeed. What does Kubernetes do?

Answer: B — A failing readinessProbe removes the Pod from Service Endpoints so it receives no traffic; only livenessProbe restarts the container.
Question 13

A Pod is in CrashLoopBackOff, and you want to inspect the logs from the container before its most recent restart. Which command should you run?

Answer: B — kubectl logs <pod> --previous (or -p) retrieves stdout/stderr from the previous terminated container instance.
Question 14

You are upgrading an older cluster manifest that uses apiVersion: extensions/v1beta1 for an Ingress. What is the correct current stable apiVersion for Ingress?

Answer: B — Ingress moved to stable networking.k8s.io/v1 in Kubernetes 1.19 (and extensions/v1beta1 was removed in 1.22).

Domain 4: Application Environment, Configuration and Security (Questions 15–20)

Question 15

You mount a ConfigMap into a Pod using volumeMounts[].subPath: app.conf, and later update the ConfigMap key app.conf. What happens inside the running container?

Answer: B — Mounting a ConfigMap or Secret with subPath prevents kubelet from updating the file when the ConfigMap/Secret changes.
Question 16

What happens when a container attempts to consume more CPU than its limits.cpu vs. more memory than its limits.memory?

Answer: B — CPU is compressible (throttled via cgroups); memory is incompressible (exceeding limits triggers kernel OOMKilled).
Question 17

A Pod has two containers:

  • Container 1: requests: { cpu: 100m, memory: 128Mi }, limits: { cpu: 100m, memory: 128Mi }
  • Container 2: requests: { cpu: 100m, memory: 128Mi }, limits: { cpu: 200m, memory: 256Mi }

What QoS class does Kubernetes assign to this Pod?

Answer: B — For Guaranteed, every container must have CPU and memory requests equal to limits. Container 2 has request != limit, making the Pod Burstable.
Question 18

A Namespace has a ResourceQuota limiting total requests.cpu and limits.memory, and no LimitRange exists in that Namespace. What happens if you try to create a Pod in that Namespace without specifying CPU requests or memory limits?

Answer: B — When a ResourceQuota constrains a compute resource (like requests.cpu), Pods must have that field set (explicitly or via a LimitRange default) or they are rejected by admission control.
Question 19

A container image runs as root (UID 0) by default, and its Pod spec sets securityContext.runAsNonRoot: true without specifying runAsUser. What happens?

Answer: B — runAsNonRoot: true does not assign a UID; it rejects starting a container whose effective UID is 0. You must also set runAsUser (or use an image with a non-root USER).
Question 20

You want to grant ServiceAccount deployer in namespace app permission to read pods only inside namespace app, using an existing cluster-wide ClusterRole named view. Which RBAC resource should you create?

Answer: B — Binding a ClusterRole with a namespaced RoleBinding grants the ClusterRole's permissions scoped only to that RoleBinding's namespace.

Domain 5: Services and Networking (Questions 21–25)

Question 21

What is the DNS name to reach a Service named payments in namespace billing from a Pod in namespace frontend?

Answer: B — Across namespaces, use <service>.<namespace>.svc.cluster.local (or <service>.<namespace>).
Question 22

A NodePort Service has port: 80, targetPort: 8080, and nodePort: 30080. External traffic hits <Node2-IP>:30080, while the only matching ready Pod is running on Node1. What happens?

Answer: B — A NodePort opens the port on every Node, and kube-proxy routes traffic to any ready backend Pod in the cluster, regardless of which Node received the connection.
Question 23

Look at the following NetworkPolicy ingress rule:

yaml
ingress:
- from:
  - namespaceSelector:
      matchLabels:
        team: alpha
    podSelector:
      matchLabels:
        role: client

Which traffic is allowed by this rule?

Answer: B — Both namespaceSelector and podSelector are under a single list item (only one - before namespaceSelector), so they are ANDed. Two separate - items would be ORed.
Question 24

If a NetworkPolicy selects a Pod with policyTypes: ["Ingress"] and specifies ingress: [] (an empty list), what is the effect?

Answer: B — Selecting a Pod with policyTypes: ["Ingress"] isolates it; an empty ingress: [] means zero allow rules, denying all incoming traffic.
Question 25

You created a Service web-svc, and curl http://web-svc times out from a test Pod. Running kubectl get endpoints web-svc returns <none>. Which is the most likely cause?

Answer: A — Empty Endpoints almost always means the Service selector doesn't match Pod labels, or the matching Pods are not Ready.
